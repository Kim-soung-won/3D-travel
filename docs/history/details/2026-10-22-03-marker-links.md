# 03. 마커에 링크 붙이기

[← 2026-10-22 일자별 기록](../daily/2026-10-22.md) · 09:15–09:35 KST

## 요청
- 도시 마커에 구글 지도 링크 같은 것을 넣을 수 있게 한다.

## 해석
- 지구본의 도시와 도시 화면의 세부 경유지 모두에 링크를 하나씩 붙일 수 있게 했습니다. 둘 다 "마커"로 보일 수 있어서입니다. 사용자에게 따로 묻지 않고 정한 것입니다.
- 링크는 사용자가 붙여 넣습니다. 자동으로 만들지는 않고, 찾으러 갈 수 있게 [구글 지도에서 찾기] 검색 링크만 둡니다.

## 한 일
- **데이터:** 경유지에 `link`를 더했습니다(`src/state/route.ts`).
- **안전:** `src/state/link.ts`의 `safeLink`가 http·https 주소만 받고 500자에서 자릅니다. 공유 링크로 받은 일정에 `javascript:` 같은 주소가 있으면 누르는 순간 스크립트가 돌 수 있어서, 읽을 때와 그릴 때 모두 거칩니다. 쓸 수 없는 링크는 일정 전체를 거부하지 않고 그 링크만 버립니다.
- **공유 형식 v2:** 링크(`u`)를 담습니다. AGENTS.md 규칙대로 버전을 올렸고 v1도 읽습니다. 링크가 없으면 길이는 그대로라 예시 일정 링크 600자 제한은 유지됩니다.
- **목록:** 고른 경유지 아래에 링크 칸과 [구글 지도에서 찾기 ↗]가 나옵니다. 칸을 떠나거나 Enter를 누르면 저장하고, 비우면 링크를 뗍니다. 잘못된 주소면 이유를 글로 보입니다. 링크가 있으면 보조 설명 옆에 "구글 지도 ↗"(네이버 지도·카카오맵·사이트 주소)가 붙습니다.
- **지구본 라벨:** 링크가 있으면 라벨 끝에 [↗] 단추가 생깁니다. 라벨 층은 클릭을 통과시키지만 이 단추만 누를 수 있습니다.
- **도시 지도 마커:** 마커 옆에 [↗] 단추가 생깁니다. 마커가 button이라 그 안에 링크를 넣을 수 없어, 마커를 감싸는 div에 나란히 둡니다.
- 모든 링크는 새 탭에서 열고 `noopener noreferrer`를 붙입니다.

## 확인
- 테스트 100개(새 5개: 주소 검사, 이름 표시, 형식 v2 왕복·v1 읽기·위험한 링크 버리기), 빌드 통과.
- 브라우저 1440·390: 잘못된 주소 거부 → 구글 지도 링크 저장 → 목록·지구본 라벨 단추(누를 수 있는지 확인) → 새로고침 후 유지 → 부산 세부 경유지에 네이버 지도 링크 → 도시 마커 단추. 넘침 0, 콘솔 오류 0.

## 남은 것
- 좁은 화면 도시 지도에서는 마커끼리 겹쳐 가려진 마커의 [↗]를 누를 수 없습니다. 원래 있던 마커 겹침 문제입니다(ROADMAP "가까운 도시 라벨 겹침"과 같은 종류).
