# 01. 전체 점검과 도시 화면 문구 수정

[← 2026-10-27 일자별 기록](../daily/2026-10-27.md) · 15:31 KST

## 요청
- 앱을 띄워 기능을 처음부터 끝까지 테스트하고, 이어서 할 일을 찾는다.
- 찾은 문제 중 1·2번(아래)을 고친다.

## 사용자 결정
- 점검에서 찾은 1번(데이터 없는 도시의 안내 문구), 2번(바뀐 것이 없는데 되돌리기 알림)을 고친다.
- 3번(도시 안 재생에 상태 글 없음)은 처음에는 미뤘다가, 이어서 고치기로 했다([02](2026-10-27-02-city-play-status.md)).

## 점검 (Playwright, 개발 서버 1440·390, 빌드 결과물 1440)
통과한 것:
- 예시 경로 불러오기
- 숙박 늘리기·줄이기
- 수단을 기차로 바꾸기
- 순서·이름 바꾸기
- 지우기와 모두 지우기 → 되돌리기
- 링크: `javascript:`는 막고 이유를 보이며, https는 저장
- 지구본 재생과 상태 글
- 공유 창(링크 587자)
- 새로고침 뒤 자동 저장 유지
- 공유 링크를 다른 창에서 열면 가져오기 확인
- 나라(미국) 눌러 도시 추가
- 도시 화면
  - 부산 추천 루트(지하철 서면 환승)와 되돌리기
  - 장소를 날마다 나누기
  - 장소 검색
  - 지도 클릭으로 장소 추가(뉴욕, 도보)
  - 도시 재생
  - 390 패널 펼치기

가로 넘침 0, 페이지 오류 0이었습니다.

찾은 것:
1. 사전 데이터가 없는 도시(뉴욕 등)에서 "검색·추천을 쓸 수 없습니다" 아래에 "추천 루트를 불러오거나 장소를 검색해 보세요"가 함께 나왔습니다.
2. 순서 최적화를 눌렀을 때 이미 가장 짧은 순서이면, 바뀐 것이 없어도 "이미 가장 짧은 순서입니다" 알림에 [되돌리기]가 붙었습니다.
3. 도시 안 재생에는 지구본처럼 진행 상태 글이 없고 진행 막대만 있습니다. 이어서 [02](2026-10-27-02-city-play-status.md)에서 고쳤습니다.
- 지도 스타일 경고는 이번에 3건(`highway-shield-*`)으로, 전에 적은 6건보다 적었습니다.

## 한 일
- `src/ui/Sidebar.tsx`: 경유지가 없을 때의 안내 문구를 고쳤습니다.
  - 사전 데이터가 없는 도시에서는 "아직 세부 경유지가 없습니다."만 보입니다. 지도 클릭 안내는 위 찾기 칸 자리에 이미 있습니다.
- `src/ui/CityGuide.tsx`: 순서 최적화 결과를 셋으로 나눴습니다.
  - 순서도 수단도 그대로이면 되돌리기 알림을 띄우지 않고, 단추 옆에 "이미 가장 짧은 순서입니다"를 보입니다. 경유지가 바뀌면 이 글은 사라집니다.
  - 순서는 그대로이고 구간 수단만 거리에 맞춰 다시 정해졌으면 "순서는 이미 가장 짧아, 구간 수단만 거리에 맞춰 다시 정함" 알림과 되돌리기를 둡니다.
  - 순서가 바뀌면 전처럼 알림과 되돌리기를 둡니다.
