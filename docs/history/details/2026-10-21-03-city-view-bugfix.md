# 03. 도시 화면 버그 수정

[← 2026-10-21 일자별 기록](../daily/2026-10-21.md) · 16:44–16:56 KST

## 배경
v0.2를 디버깅 포트 Chrome으로 처음부터 끝까지 돌렸습니다. 순서는 예시 경로 → 서울 진입 → 지도 클릭 → 재생 → 지구 복귀 → 좁은 화면입니다. 이 시나리오에서 나온 문제를 고쳤습니다.

## 고친 것
| 증상 | 원인 | 수정 |
| --- | --- | --- |
| 도시 지도가 하얗게 비고 클릭도 안 됨 | MapLibre가 컨테이너에 `position: relative`를 덮어써서, `absolute; inset: 0`이던 지도 영역의 높이가 0이 됨 | 크기는 바깥 div(`.city-map`)가 정하고, 지도는 안쪽 div(`.city-map-canvas`, 100%)에 붙임 |
| 도시 화면에 경유지 마커가 없음 | 스타일을 비동기로 불러온 뒤 지도가 생기는데, 마커 effect가 그보다 먼저 돌고 끝남 | `loaded` 상태를 두고 마커·구간 effect의 의존성에 넣음 |
| 재생해도 출발점에서 멈춤(진행률 0) | `useLegs`가 렌더마다 새 배열을 돌려줘, 진행률이 바뀔 때마다 재생 effect가 처음부터 다시 시작 | 결과를 `useMemo`로 고정 |
| 지구본을 내릴 때 콘솔 오류 6건 ("synchronously unmount a root while React was already rendering") | drei `Html` 라벨이 언마운트 중 내부 root를 동기 해제 | 라벨을 캔버스 밖 DOM 레이어(`PinLabels`)로 옮기고, `useFrame`에서 화면 좌표와 투명도를 씀 |
| "총 거리 19,257 km"가 글자 단위로 두 줄로 깨짐 | flex 항목이 줄어들며 줄바꿈 | 라벨·값은 `nowrap`, 설명은 다음 줄로 내려가게 `flex-wrap` |

## 재현 안 됨
- **서울을 눌렀는데 부산으로 들어간 현상:** 추적 코드를 넣고 다시 해 보니 서울로 정상 진입했습니다.
- **재생 중 클릭하지 않은 지점(북위 40도 부근)이 경유지로 추가된 현상:** 1회 나왔고 이후 4회는 나오지 않았습니다.
- 두 건 모두 코드를 고치는 동안 개발 서버가 페이지를 자동 갱신(HMR)한 것과 겹쳤을 가능성이 있습니다. 확인하지는 못했습니다.

## 바뀐 파일
`src/city/CityView.tsx`, `src/hooks/useLegs.ts`, `src/scene/Pins.tsx`, `src/scene/Scene.tsx`, `src/styles.css`, `README.md`, `AGENTS.md`

## 확인
- 시나리오를 연속 4회 돌려 모두 정상이었고, 콘솔 오류는 0건이었습니다.
- 확인한 항목: 재생 진행, 지도 클릭 추가, 지구 복귀. 390px 폭에서 가로 넘침도 0이었습니다.
- 테스트 24개와 빌드가 통과했습니다.
- AGENTS.md에 재발 방지 규칙 3가지를 적었습니다: Html 금지, `loaded` 의존성, 바깥·안쪽 div 분리.

## 남은 문제
- 서울·부산처럼 가까운 도시는 멀리서 보면 라벨이 겹칩니다.
