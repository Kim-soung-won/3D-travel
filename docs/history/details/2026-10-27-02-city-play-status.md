# 02. 도시 안 재생 상태 글

[← 2026-10-27 일자별 기록](../daily/2026-10-27.md) · 16:08 KST

## 요청
- [01 점검](2026-10-27-01-walkthrough-fixes.md)의 3번: 도시 안 재생에는 지구본처럼 진행 상태 글이 없고 진행 막대만 있었다. 이것도 고친다.

## 사용자 결정
- 도시 안 재생에도 상태 글을 보인다.
- 날을 골라 재생하는 것은 이번 요청에 들어 있지 않아 ROADMAP "결정 필요"에 그대로 둔다.

## 한 일
- 상태 글 형식은 지구본과 같게 맞췄습니다: "1일차 · 지하철로 서울역 → 명동".
  - 앞의 날 이름은 패널의 날 머리와 같습니다(날짜를 정했으면 "10/24(토)", 아니면 여행 전체의 "n일차").
  - 날이 바뀌는 구간(전날 마지막 장소 → 다음 날 장소)은 다음 날 아침 이동으로 보고, 도착하는 장소의 날을 씁니다.
- `src/city/CityView.tsx`: 재생 중 달리는 구간이 바뀔 때만 `onLeg(i)`를 부릅니다. 매 프레임 React 상태를 바꾸지 않습니다.
- `src/App.tsx`: 지금 구간 번호를 들고 있다가 도시 패널에 넘깁니다. 재생을 시작하거나 멈출 때 비웁니다.
- `src/ui/Sidebar.tsx`: CitySidebar가 구간 번호와 날 이름으로 상태 글을 만들어 아래쪽에 보입니다.
- `src/geo/modes.ts`: "지하철로 A → B" 토막(`travelLine`)을 지구본 재생(`Traveler.tsx`)과 함께 씁니다.

## 바뀐 파일
- `src/city/CityView.tsx`
- `src/App.tsx`
- `src/ui/Sidebar.tsx`
- `src/geo/modes.ts`
- `src/scene/Traveler.tsx`

## 확인
- 테스트 124개, 빌드 통과. 지구본 상태 글 테스트(`Traveler.test.ts`)는 바뀌지 않고 통과.
- 브라우저(1440·390): 예시 서울에서 성수동을 2일째로 옮긴 뒤 재생. 상태 글은 아래 순서로 나왔습니다.
  1. "1일차 · 지하철로 서울역 → 명동"
  2. "1일차 · 걸어서 명동 → 경복궁"
  3. "2일차 · 버스로 경복궁 → 성수동"
- 재생이 끝나면 상태 글이 사라집니다.
- 지구본 재생 상태 글("3일차 · 비행기로 서울특별시 → 부산광역시")은 그대로이고, 페이지 오류는 0입니다.

## 남은 문제
