# 01. 보는 동안 저절로 움직이는 장식 멈추기

[← 2026-10-22 일자별 기록](../daily/2026-10-22.md)

## 요청
- 사용자가 화면에 포커스가 있으면 자동으로 움직이는 애니메이션이 멈춰야 한다.

## 해석
- "저절로 움직이는 것"은 빈 지구본의 자동 회전과 구름 흐름으로 봤습니다. 클릭하려는 곳이 움직이면 엉뚱한 지점이 찍히기 때문입니다.
- 경로선의 점선 흐름은 이동 방향을 알려 주는 표시라 그대로 두었습니다. 재생 중 카메라 이동도 사용자가 시작한 것이라 그대로입니다.
- "포커스"는 다음 둘 중 하나로 정했습니다. 사용자에게 따로 묻지 않고 정한 것입니다.
  - 포인터가 지구본 위에 있다(가만히 두어도 유지).
  - 최근 4초 안에 창 어디서든 포인터·휠·키보드 조작이 있었다.

## 한 일
- `src/scene/attention.ts`: 조작 감지(`AttentionTracker`), 판단(`isAttending`), 속도 배율(`easeMotion`).
  - 핀 라벨 DOM 층이 캔버스를 덮고 있어 `pointerenter` 대신 좌표로 지구본 위인지 판단합니다.
  - 터치는 "올려 둔 상태"가 없어 마지막 조작 시각만 봅니다.
  - 운영체제의 "동작 줄이기" 설정이 켜져 있으면 늘 멈춥니다.
- `CameraRig`: 자동 회전 속도를 배율에 맞춰 바꿉니다. 멈출 때는 빨리(체감 약 1초, 카메라 감쇠 포함), 다시 돌 때는 1초 남짓에 걸쳐 천천히.
- `Clouds`: 같은 배율로 멈춥니다.

## 확인
- 테스트 87개, 빌드 통과.
- 브라우저(1440, 빈 일정): 조작 없음 → 회전, 지구본 위에 포인터를 두면 약 1.2초 뒤 화면이 멈추고 7.5초 뒤에도 멈춰 있음, 패널로 옮긴 뒤 4초가 지나면 다시 회전. 콘솔 오류 0.
