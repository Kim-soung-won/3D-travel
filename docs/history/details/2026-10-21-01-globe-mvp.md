# 01. 지구본 경로 그리기 MVP (v0.1)

[← 2026-10-21 일자별 기록](../daily/2026-10-21.md) · 16:23–16:32 KST

## 요청
- 여행 경로를 지구본 형태의 WebGL로 짜는 웹 앱을 만든다.
- 참고 대상은 [Messenger](https://messenger.abeto.co/)(abeto)처럼 "하나의 작은 세계"에서 시작하는 웹 게임이다. 같은 날 앞서 구조를 분석한 사이트다.

## 사용자 결정
| 질문 | 선택 |
| --- | --- |
| 지구본 모습 | 스타일화된 작은 지구 |
| 기술 | React + three.js (React Three Fiber) |
| 첫 버전 범위 | 경로 그리기 MVP |

## 한 일
- **프로젝트:** Vite 7 + React 19 + TypeScript. three.js r180, React Three Fiber 9, drei 10을 씁니다.
- **지구본:**
  - 툰 셰이딩, 외곽선, 대기 테두리, 떠다니는 구름을 넣었습니다.
  - 대륙·국경은 Natural Earth 1:110m(`world-atlas`, `topojson-client`, `d3-geo`)를 캔버스 텍스처로 그렸습니다.
- **경유지 추가:**
  - 지구본을 클릭하면 경유지가 추가되고, 그 지점의 나라 이름이 자동으로 붙습니다. 외부 API 없이 지도 데이터로 판별합니다.
  - 드래그로 돌린 뒤 손을 떼는 동작은 클릭으로 치지 않습니다.
- **경로:**
  - 경유지 사이를 대권 곡선으로 잇고, 먼 구간일수록 높이 솟게 그립니다.
  - 거리는 하버사인 공식으로 계산합니다. 서울–도쿄 1,149km로 실제 값과 맞는지 확인했습니다.
- **목록 편집:** 이름 바꾸기, 순서 이동, 삭제. 경유지를 고르면 카메라가 그곳으로 날아갑니다.
- **여행 재생:** 비행기가 경로를 날고 카메라가 따라갑니다. 진행률을 보여 주고, Esc로 멈춥니다.
- **지우기:** 확인 창 없이 바로 지우고 [되돌리기]를 줍니다. 할 수 없는 동작(경유지 2곳 미만 재생)은 이유를 화면 글로 보입니다. 이웃 프로젝트 `dashboard-design-principles`의 원칙을 따른 것입니다.
- **좁은 화면:** 720px 이하에서는 패널이 아래로 내려가고, 카메라가 화면 비율에 맞춰 물러납니다(`CameraRig`의 `fit`).

## 확인하면서 고친 것
- 지구본이 패널에 가려지고, 핀 라벨이 패널 위에 겹치던 것
- 지구 뒤편 라벨이 보이던 것. drei의 가림 기능이 동작하지 않아, 카메라 방향과 법선으로 투명도를 직접 계산했습니다.
- 재생 중 카메라가 너무 가깝던 것
- 모바일에서 지구본 양옆이 잘리던 것

- 장소 검색과 저장·공유가 없습니다.
