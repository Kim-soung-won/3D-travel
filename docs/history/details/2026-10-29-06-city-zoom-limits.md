# 06. 도시 지도 확대·축소 범위 제한

[← 2026-10-29 일자별 기록](../daily/2026-10-29.md) · 10:36 KST

## 요청
- 도시 화면 지도의 확대·축소에 제약을 추가한다.

## 사용자 결정
- 도시 화면에 확대·축소 제약을 둔다. 범위 값은 따로 정하지 않아 아래처럼 정했다.

## 한 일
- `src/city/CityView.tsx`: 지도에 `minZoom: 10`, `maxZoom: 18`을 줍니다(`CITY_ZOOM`).
  - **축소 10:** 넓은 화면에서 가로 약 140km입니다. 제주 섬 전체나 서울 수도권이 들어갑니다. 더 물러나면 도시를 벗어나 지구본 화면과 겹칩니다.
  - **확대 18:** 건물·골목 단위입니다. 지도 타일은 14까지라, 더 당기면 늘려 그릴 뿐이라 흐려집니다.
- 한계에 닿으면 MapLibre가 +/− 단추를 스스로 끕니다. 휠·두 손가락도 범위 안에서 멈춥니다.
- 기존 경로 맞춤(최대 15)과 지하철역 점(12.5부터 보임)은 범위 안이라 그대로입니다.

## 바뀐 파일
- `src/city/CityView.tsx`

## 확인
- 테스트 185개, 빌드 통과.
- 브라우저(1440·390), 서울 도시 화면
  - − 단추를 끝까지 누르면 단추가 꺼지고 수도권 전체가 보임
  - 그 뒤 휠로 더 축소해도 그대로
  - + 단추를 끝까지 누르면 단추가 꺼지고 건물 단위
  - 페이지 오류 0

## 남은 문제
- 지도를 옆으로 끄는 범위(이동 범위)는 제한하지 않았습니다. 축소 한계 안에서는 도시 밖으로 멀리 끌고 갈 수 있습니다.
