# 02. 지구본은 나라 고르기 → 주요 도시 고르기

[← 2026-10-22 일자별 기록](../daily/2026-10-22.md) · 08:46–09:10 KST

## 요청
- 지구 화면에서는 나라 단위 선택만 되게 한다. 나라를 고른 뒤 도시를 고르는 순서가 맞다.

## 사용자 결정
| 질문 | 선택 |
| --- | --- |
| 나라를 고른 뒤 도시는 어떻게 고르나 | **주요 도시 목록.** Natural Earth(퍼블릭 도메인) 데이터를 앱에 넣는다 |
| 지구본 아무 곳이나 눌러 바로 경유지를 넣던 방식 | **없앤다.** 지구본 클릭은 늘 나라 고르기 |

## 한 일
### 데이터 (`scripts/build-places.mjs` → `src/data/places.json`)
- 원본: Natural Earth 1:10m populated places(도시 7,342곳, 한국어 이름 포함), 1:110m admin 0 countries(나라 한국어 이름).
  - 원본 두 파일(약 20MB)은 저장소에 넣지 않습니다. 스크립트 머리말에 받는 곳과 실행 방법이 있습니다.
- 나라 키는 지구본 클릭 판정에 쓰는 world-atlas 이름입니다. 도시는 `ADM0_A3`(없으면 `ISO_A3`)로 나라에 붙입니다.
  - world-atlas가 만들어진 뒤 바뀐 이름 1건(Macedonia → North Macedonia)은 스크립트에서 맞춥니다.
- 나라마다 인구순 최대 20곳, 수도는 늘 포함. 결과는 나라 177곳, 도시 2,566곳입니다. 도시가 없는 곳은 프랑스령 남방 지역 1곳입니다.
- 크기는 138KB(gzip 67KB)입니다. 메인 번들에 넣지 않고, 처음 나라를 누를 때 별도 청크로 불러옵니다.
- 나라 한국어 이름은 기존 짧은 이름표(중국, 미국 등)를 먼저 쓰고, 없으면 Natural Earth 이름을 씁니다. 이전에는 일부 나라만 한국어였습니다.

### 화면
- **지구본 클릭:** 누른 곳의 나라를 고릅니다. 바다를 누르면 고른 나라가 풀립니다. 주소 조회(Nominatim)는 지구본에서 더 이상 부르지 않습니다.
- **고른 나라:** 땅을 주황으로 칠하고 국경을 굵게 그립니다. 카메라는 나라의 가장 넓은 땅덩이 중심으로 가고, 나라 크기에 맞춰 다가갑니다(프랑스령 기아나 같은 해외 영토에 끌려가지 않게 하기 위해서입니다).
- **도시 점:** 고른 나라의 도시를 지구본에 점으로 찍습니다(수도는 조금 크게). 점을 누르면 추가되고, 점에 포인터를 올리면 패널의 같은 줄이 강조됩니다. 판정 영역은 점보다 넓습니다.
- **패널:** 나라 이름, 도시 수, [×] 닫기. 줄마다 한국어·영어 이름, 수도 표시, 인구, "일정에 있음", "+ 추가". 아래에 데이터 출처를 적었습니다.
- **닫기:** [×], Esc, 바다 클릭. 재생을 시작하거나 도시 화면에 들어가도 닫힙니다.
- 같은 도시를 다시 넣는 것은 막지 않았습니다. 돌아오는 일정이 있을 수 있어서입니다. 대신 "일정에 있음"을 보입니다.

## 확인
- 테스트 95개(새 8개: 데이터 형식, 수도를 누르면 그 나라가 골라지는지 85% 이상, 서울·파리, 나라 중심), 빌드 통과.
- 브라우저 1440·390: 나라 누르기 → 칠함·점·목록 → 목록에서 추가 → 점을 눌러 추가 → Esc로 닫기. 넘침 0, 콘솔 오류 0.

## 남은 것
- 나라 안 도시 이름 검색은 고르지 않았습니다. 목록은 나라마다 20곳까지입니다(ROADMAP 다음 후보).
- 1:110m 국경이라 싱가포르 같은 작은 나라는 지구본에서 고를 수 없습니다(ROADMAP 알려진 문제).
