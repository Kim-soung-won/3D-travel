## 한 일
### 형식 v1 (`src/share/format.ts`)
- 링크, 파일, 자동 저장이 같은 형식을 씁니다. 짧은 키를 쓰고, 좌표는 소수 5자리까지만 담습니다.
- 경로선은 담지 않고 받는 쪽에서 다시 계산합니다.
- **읽을 때의 검사:**
  - 버전, 좌표 범위, 수단 값을 확인합니다.
  - 이름은 80자, 도시·세부 경유지는 각 100곳까지 받습니다. 숙박 수는 0~30으로 자릅니다.
  - id는 새로 붙입니다.
  - 틀리면 이유를 담은 `TripFormatError`를 냅니다.

### 1. 자동 저장 (`src/share/storage.ts`)
- 일정이 바뀌면 0.3초 뒤 `localStorage`(`travel-globe:trip:v1`)에 저장하고, 시작할 때 읽어 옵니다.
- 저장소가 막혀 있거나 내용이 깨져 있으면 빈 일정으로 시작합니다.

### 2. 공유 링크 (`src/share/codec.ts`, `src/ui/ShareDialog.tsx`)
- **인코딩:** JSON → `CompressionStream('deflate-raw')` → base64url. 새 라이브러리는 쓰지 않았습니다.
- **위치:** 링크의 `#trip=` 뒤에 담아 호스팅 서버로 보내지지 않게 했습니다.
- **받는 쪽:**
  - 링크로 열면 주소의 일정 부분을 바로 지우고 "공유받은 일정" 미리보기를 띄웁니다. 미리보기에는 일정, 도시별 박 수·일차, 세부 경유지 수가 보입니다.
  - [내 일정으로 가져오기]를 눌러야 바뀌고, 원래 일정은 [되돌리기]로 돌아갈 수 있습니다.
- **잘린 링크:** "링크가 잘렸거나 손상되었습니다"를 보이고 내 일정은 그대로 둡니다.
- **로컬 주소 경고:** localhost·127.0.0.1에서 링크를 만들면 "이 컴퓨터에서만 열립니다"를 보입니다.
- **복사·공유 시트:** [링크 복사]가 실패하면 직접 복사하라고 안내합니다. 공유 시트를 지원하는 브라우저에서는 [다른 앱으로 링크 보내기]도 나옵니다.

### 3. 배포 준비
- `.node-version`(22)을 추가했습니다.
- `index.html`에 description과 og 메타 태그를 넣었습니다.
- README에 Cloudflare Pages 연결 절차를 적었습니다: 빌드 명령 `npm run build`, 출력 `dist`.
- **실제 연결은 하지 않았습니다.** Cloudflare 로그인과 GitHub 권한 허용은 사용자가 직접 해야 합니다.

### 4. 이미지 카드 (`src/share/card.ts`)
- 1080×1350 PNG입니다.
  - 머리: "11박 12일"과 도시 수·직선 거리
  - 지구본: 경로 중심을 바라보는 2D 정사영. 구간은 수단 색으로 그리고 비행기는 점선입니다. 번호 핀을 찍습니다.
  - 일정표: 박·일차·다음 수단. 넘치면 "외 n곳"으로 줄입니다.
- WebGL 화면을 캡처하지 않고 다시 그려서, 카메라 각도나 재생 상태와 관계없이 늘 같은 모양이 나옵니다.
- [이미지 저장]이 있고, 파일 공유를 지원하는 기기에서는 [이미지 보내기]도 나옵니다.

### 5. 파일 (`ShareDialog`)
- [파일로 내보내기]는 같은 형식의 `.json`을 들여쓰기해 저장합니다.
- [파일 가져오기]로 연 파일은 링크와 같은 미리보기를 거쳐 가져옵니다. 1MB를 넘거나 형식이 틀린 파일은 이유를 보입니다.
