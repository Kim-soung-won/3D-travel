# 02. 도시 단위와 지면 이동 수단 (v0.2)

[← 2026-10-21 일자별 기록](../daily/2026-10-21.md) · 16:33–16:44 KST

## 요청
- 국가 단위에서 도시 안 세부 단위까지 지원한다.
- 비행기 말고 버스, 지하철처럼 지면을 달리는 수준까지 확대·축소할 수 있게 한다.

## 사용자 결정
| 질문 | 선택 |
| --- | --- |
| 지면 수준으로 가는 방식 | Messenger 같은 연속 확대(zoom)가 아니라, **로딩 화면을 거쳐 화면 자체를 전환**한다. 그러면 더 가벼울 것이라는 이유 |
| 버스·지하철 경로 | 실제 도로를 따라 그린다 |
| 지하철 | 당시에는 노선 데이터가 없어 직선으로 그리기로 합의했다. [04](2026-10-21-04-ai-prebuilt-data.md)에서 노선 데이터로 바뀌었다 |

## 한 일
- **수단 5가지(`src/geo/modes.ts`):** 비행기·버스·자동차·지하철·도보. 수단마다 색, 선 모양, 도로 프로필, 시간 어림 방법이 다릅니다.
- **상태 확장(`src/state/route.ts`):**
  - 도시(경유지)마다 세부 경유지(`stops`)를 두고, 지점마다 "다음 지점까지의 수단"을 저장합니다.
  - 세부 경유지용 액션(add/remove/move/update/clear)과 되돌리기를 넣었습니다.
- **화면 전환:**
  - [도시 안 경로 짜기 →]를 누르면 로딩 화면(`LoadingScreen`)이 덮고, 지구본을 내린 뒤 도시 지도를 올립니다.
  - 새 화면이 첫 프레임을 그리면 최소 노출 시간(0.5초)을 채운 뒤 걷습니다.
  - 지구본과 도시 지도는 동시에 떠 있지 않습니다. 도시 화면은 처음 들어갈 때만 불러오는 별도 청크(lazy)입니다.
- **도시 지도(`src/city/`):**
  - MapLibre GL 5 + OpenFreeMap `liberty` 스타일을 씁니다. 키가 필요 없습니다.
  - 지명은 한국어를 먼저 쓰도록 스타일을 고쳤습니다(`mapStyle.ts`).
- **도로 경로(`src/geo/routing.ts`):**
  - 버스·자동차는 FOSSGIS OSRM `routed-car`, 도보는 `routed-foot`를 씁니다.
  - 같은 구간은 메모리에 캐시합니다. 실패하면 직선으로 대신 그리고 이유를 표시합니다.
  - 버스 시간은 자동차 시간의 1.5배로 어림합니다.
- **장소 이름(`src/geo/geocode.ts`):** Nominatim reverse(`accept-language=ko`)를 씁니다. 공개 서버 정책에 맞춰 1.1초 간격 큐로 요청합니다.
- **임시 이름 보호:** 이름 조회가 끝나기 전에 사용자가 바꾼 이름은 덮어쓰지 않습니다.
- **예시 경로:** 서울(세부 경유지 4곳) → 부산 → 도쿄 → 샌프란시스코 → 로스앤젤레스 → 파리
