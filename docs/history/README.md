| 위치 | 내용 | 분량 |
| --- | --- | --- |
| [daily/](daily/) | 그날 한 일, 사용자 결정, 남은 일 | 작업 하나에 한두 줄 |
| [details/](details/) | 작업 하나의 배경, 결정, 바뀐 것, 확인 방법, 남은 문제 | 제한 없음 |
| [../plan/ROADMAP.md](../plan/ROADMAP.md) | 앞으로 할 일과 상태 | 항목마다 한 줄 + 링크 |

## 쓰는 법
- **파일 이름:**
  - 일자별: `daily/YYYY-MM-DD.md`
  - 상세: `details/YYYY-MM-DD-NN-<주제>.md`. `NN`은 그날 안의 순번입니다.
- **연결:**
  - 일자별의 각 줄은 상세로 링크합니다.
  - 상세는 맨 위에서 일자별로, 맨 아래에서 이전·다음 상세로 링크합니다.
  - 계획 항목이 끝나면 ROADMAP에서 "완료"로 옮기고 상세를 링크합니다.
- **상세 문서의 절 순서:** 요청 → 사용자 결정 → 한 일 → 바뀐 파일 → 확인 → 남은 문제
- **사실만 적는다:**
  - 확인한 것과 추정을 구분합니다.
  - 재현하지 못한 문제는 "재현 안 됨"으로 남깁니다.
  - 시각은 한국 시간(KST)으로 적습니다.
- **결정은 사용자가 한다:**
  - 선택지를 고른 사람과 고른 내용을 "사용자 결정"에 적습니다.
  - 아직 정하지 않은 일은 ROADMAP의 "결정 필요"에 둡니다.
