## 다음 후보 (작업 결정만 나면 바로 할 수 있는 것)
- **서버 저장 + 짧은 링크·공동 편집:** 사용자가 "나중에 도입 검토"를 골랐습니다. 도입하려면 DB와 키 관리 방식부터 따로 계획해야 합니다. → [공유 계획](sharing.md)의 B안
- **이미지 카드 장식:** 도시 사진 등을 더할지 정해야 합니다.
- **사전 데이터를 도시 화면 청크로 옮기기:** 메인 번들 1.45MB가 줄어듭니다. 도시가 늘면 필요합니다.
- **좁은 화면 도시 패널:** 세부 경유지 목록이 패널 안을 스크롤해야 보입니다. 검색·추천을 접거나 패널을 끌어 올리는 방식 등이 필요합니다. ([2026-10-22 08](../history/details/2026-10-22-08-full-check.md))
- **가까운 도시 라벨 겹침 처리:** 서울·부산처럼 가까운 도시를 멀리서 볼 때 라벨이 겹칩니다. 도시 지도에서도 마커가 겹치면 가려진 마커의 링크 단추를 누를 수 없습니다.
- **되돌리기 알림 범위:** 도시를 옮겨도 이전 도시의 되돌리기 알림이 남습니다.
- **비행 곡선과 숙소 모형 겹침:** 출발 도시에서 솟는 비행 곡선이 숙소 모형을 관통해 보일 때가 있습니다.
- **나라 안 도시 이름 검색:** 지금은 나라마다 인구순 20곳 목록만 있습니다. 작은 도시까지 찾으려면 검색 칸과 더 큰 데이터가 필요합니다. ([2026-10-22 02](../history/details/2026-10-22-02-country-then-city.md)에서 사용자가 목록만 고름)
- **사전 데이터 검토:** 생성 쪽이 불확실하다고 밝힌 역·좌표가 있습니다. 목록은 [04 상세](../history/details/2026-10-21-04-ai-prebuilt-data.md)에 있습니다.

## 보류
- **실시간 AI 검색·추천:** 사용자가 "실시간 AI 없이"를 골랐습니다. 다시 하려면 키 관리 방식을 정해야 합니다. 선택지는 개발 서버 중계 + `.env.local`, 또는 로컬 모델입니다.
- **공개 서버 교체:** 실제 서비스로 낼 때만 필요합니다. 대상은 OpenFreeMap, OSRM, Nominatim이고, 지금은 시제품 용도입니다.
