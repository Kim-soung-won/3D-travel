## 사용자 결정 (2026-10-29)
- 도시 안 재생: 날 고르기 (기본 모든 날)
- 공항 대기: 비행 구간마다 2시간
- 순서 최적화 기준: 직선 거리 유지. 구간 이동 시간·영업시간 기준은 하지 않음
- 바다를 건너는 기차: 막음 (사전 데이터에 기차 시간이 있는 구간은 통과)
- 도시 추가: 오사카·교토·뉴욕·런던·방콕·싱가포르·타이베이·제주
- 공항: 공항 데이터·공항 사이 비행·공항 고르기·공항 오가는 시간까지. 도시 화면의 공항 구간은 하지 않음

## 다음 후보 (작업 결정만 나면 바로 할 수 있는 것)
- **서버 저장 + 짧은 링크·공동 편집:** 사용자가 "나중에 도입 검토"를 골랐습니다. 도입하려면 DB와 키 관리 방식부터 따로 계획해야 합니다. → [공유 계획](sharing.md)의 B안
- **이미지 카드 장식:** 도시 사진 등을 더할지 정해야 합니다.
- **사전 데이터 검토:** 생성 쪽이 불확실하다고 밝힌 역·좌표가 있습니다. 목록은 [2026-10-21 04](../history/details/2026-10-21-04-ai-prebuilt-data.md), [2026-10-29 04](../history/details/2026-10-29-04-more-cities.md)에 있습니다.

## 보류
- **실시간 AI 검색·추천:** 사용자가 "실시간 AI 없이"를 골랐습니다. 다시 하려면 키 관리 방식을 정해야 합니다. 선택지는 개발 서버 중계 + `.env.local`, 또는 로컬 모델입니다.
- **공개 서버 교체:** 실제 서비스로 낼 때만 필요합니다. 대상은 OpenFreeMap, OSRM, Nominatim이고, 지금은 시제품 용도입니다.
